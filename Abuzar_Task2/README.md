# Task 2 — Unemployment Analysis with Python

## Project Overview

This project analyzes unemployment data in India to identify regional and time-based patterns in unemployment rates.

The analysis also examines changes in unemployment during the COVID-19 period.

## Objective

The main objective is to explore unemployment trends across different regions and compare unemployment conditions before and after the COVID-19 period.

## Dataset

The project uses the `Unemployment in India` dataset, which contains information such as:

- Region
- Date
- Estimated Unemployment Rate
- Estimated Employed
- Estimated Labour Participation Rate

## Data Preparation

The dataset was examined and prepared by:

- Checking the dataset shape
- Checking data types
- Checking missing values
- Converting the date column into a suitable date format
- Preparing the data for time-series analysis

## Exploratory Data Analysis

The following analyses were performed:

- Region-wise average unemployment rate
- Month-wise unemployment trends
- Time-series comparison of major regions
- Top 10 regions with the highest average unemployment rate
- Correlation between unemployment, employment, and labour participation rates

## Visualizations

The project includes:

- Time-series line charts
- Bar chart of regions with the highest average unemployment
- Correlation heatmap
- Other exploratory visualizations

## COVID-19 Analysis

The data was divided into pre-COVID and post-COVID periods to compare the average unemployment rate, employment rate, and labour participation rate.

This comparison helps identify how the labour market changed during the pandemic period.

## Key Observations

The analysis shows that unemployment rates varied considerably between regions and also changed over time.

The COVID-19 period was associated with noticeable changes in unemployment and employment-related indicators across several regions.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Conclusion

This project demonstrates how exploratory data analysis and visualization can be used to understand unemployment patterns. The regional and time-based analysis provides useful insights into changes in India's labour market, including the impact observed during the COVID-19 period.
