# OASIS INFOBYTE — Data Science Internship

## Overview

This repository contains the projects completed as part of my Data Science Internship at Oasis Infobyte.

The internship provided practical experience in data analysis, data visualization, machine learning, regression, classification, and natural language processing using Python.

## Internship Tasks

### Task 1 — Iris Flower Classification

A machine learning classification project that predicts the species of an iris flower using its physical measurements.

**Techniques Used:**
- Exploratory Data Analysis
- Data Visualization
- Feature Analysis
- Logistic Regression
- Random Forest Classification
- Classification Metrics
- Confusion Matrix

**Dataset:** Iris dataset from Scikit-learn

---

### Task 2 — Unemployment Analysis with Python

An exploratory data analysis project focused on unemployment trends in India and changes observed during the COVID-19 period.

**Techniques Used:**
- Data Cleaning
- Exploratory Data Analysis
- Regional Analysis
- Time-Series Analysis
- Correlation Analysis
- Data Visualization
- COVID-19 period comparison

**Dataset:** Unemployment in India dataset

---

### Task 3 — Car Price Prediction

A machine learning regression project that predicts the selling price of used cars based on different vehicle characteristics.

**Techniques Used:**
- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis
- Categorical Encoding
- Linear Regression
- Random Forest Regression
- MAE, RMSE and R² evaluation
- Feature Analysis

**Dataset:** Vehicle Dataset from CarDekho

---

### Task 4 — Email Spam Detection

A Natural Language Processing project that classifies text messages as spam or legitimate messages.

**Techniques Used:**
- Text Preprocessing
- Lowercase Conversion
- Stopword Removal
- TF-IDF Vectorization
- Multinomial Naive Bayes
- Logistic Regression
- Precision, Recall and F1-score
- Confusion Matrix

**Dataset:** SMS Spam Collection dataset

---

### Task 5 — Sales Prediction

A regression project that predicts product sales based on advertising expenditure across TV, Radio, and Newspaper channels.

**Techniques Used:**
- Exploratory Data Analysis
- Correlation Analysis
- Data Visualization
- Linear Regression
- Random Forest Regression
- MAE, RMSE and R² evaluation
- Residual Analysis
- Feature Importance

**Dataset:** Advertising dataset

---
